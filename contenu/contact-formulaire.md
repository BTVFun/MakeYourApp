# Contact & formulaire

## Contenu extrait

- Honeypot label : « Votre société »
- Champs :
  - Nom complet (placeholder « Alex Martin », requis)
  - Email (placeholder « vous@exemple.com », requis)
  - Téléphone (placeholder « +33 6 12 34 56 78 », optionnel)
  - Sujet (options : Site vitrine, SaaS simple, E-commerce, Utilisation Personnelle, Autre)
  - Délai (options : < 2 semaines, 2-4 semaines, > 1 mois, Flexible)
  - Budget (options : < 500 €, < 1 000 €, 1 000 - 3 000 €, 3 000 - 7 000 €, 7 000 - 15 000 €, > 15 000 €, Autre (préciser))
  - Budget (précisez) — obligatoire si option Autre
  - Description (min 20 caractères, helper « Minimum 20 caractères... »)
  - Case à cocher : « J’accepte d’être contacté(e) et la politique de confidentialité. »
- Bouton : « Envoyer mon brief », état attente « Envoi... »
- Messages :
  - Succès : « Merci, on revient vers vous sous 24h. »
  - Erreurs génériques : « Une erreur est survenue. », « Merci de vérifier le formulaire. »
  - Erreurs champ (schema) :
    - Nom : « Merci d'indiquer votre nom complet. »
    - Email : « Email invalide. »
    - Téléphone : « Téléphone trop long. »
    - Sujet : « Choisissez un sujet. »
    - Délai : « Sélectionnez un délai. »
    - Budget : « Sélectionnez un budget. »
    - Budget personnalisé : « Budget personnalisé : 60 caractères maximum. », « Précisez votre budget. »
    - Description : « Décrivez votre projet en quelques lignes (min. 20 caractères). »
    - Consentement : « Le consentement est requis. »
- Emails utilisés :
  - Contact général : `makeyourappp@gmail.com`
  - DPO : `dpo@makeyourapp.fr`
- Notification interne (mail HTML) :
  - Objet : « Nouveau lead MakeYourApp »
  - Intro : « Un formulaire vient d’être rempli depuis le site vitrine. »

## Version optimisée

### Micro-copy formulaire
- Titre : « Décrivez votre projet de site web en Europe »
- Intro : « Plus vous nous donnez de détails sur vos marchés cibles (France, Benelux, DACH, Europe du Sud), plus notre proposition sera précise. »

### Champs proposés
| Champ | Détails SEO / accessibilité |
| --- | --- |
| Nom & société | Scinder en « Nom complet » + « Organisation / pays » pour contextualiser les besoins européens. |
| Email professionnel | Placeholder : `prenom.nom@entreprise.eu`. |
| Téléphone & fuseau horaire | Ajout d’un sélecteur pays UE pour faciliter les rendez-vous. |
| Type de projet | Options mises à jour : Site vitrine premium, SaaS B2B, E-commerce multilingue, Web app interne, Refonte accessibilité, Autre. |
| Marchés ciblés | Liste à cocher (France, Belgique, Suisse, Espagne, Italie, Allemagne, UK, Autre). |
| Délai | < 1 mois, 1-2 mois, 3+ mois, À définir. |
| Budget | Fourchettes réalistes (10 k€ à 80 k€) + champ devis global. |
| Description | Encourager à préciser objectifs SEO, intégrations, langues, contraintes RGPD. |
| Ressources existantes | Lien vers maquettes, cahier des charges, site actuel. |
| Consentement | Texte RGPD : « En soumettant ce formulaire, vous acceptez que MakeYourApp (Île-de-France) vous contacte pour répondre à votre demande. » |

### Messages
- Succès : « Merci ! Un expert basé en Île-de-France vous recontacte sous 24 h ouvrées pour planifier un briefing en visio. »
- Erreur générique : « Impossible d’envoyer le formulaire. Merci de réessayer ou d’écrire à bonjour@makeyourapp.eu. »
- Ajout d’un message de confirmation secondaire : « Vous recevrez un récapitulatif de votre brief par e-mail. »

### Notifications internes
- Objet e-mail : « Nouveau projet site web Europe – {sujet} »
- Corps : rappeler fuseau horaire, budget, marché cible, priorités SEO/accessibilité.
