- Intro : rappel RGPD, traitements, droits, champ d’application.
- Sections :

## Version optimisée

### Résumé clair
« MakeYourApp, agence de création de sites web située en Île-de-France, traite les données collectées via makeyourapp.eu pour répondre aux demandes clients européens et suivre les performances de son site. »

### Traitements détaillés
- **Formulaire de contact / devis** : collecte nom, société, pays, e-mail, téléphone, description, budget, fuseau horaire, marchés visés. Base légale : intérêt légitime + mesures précontractuelles.
- **Outils analytics européens** : Matomo hébergé en UE ou Plausible (sans cookies), déploiement uniquement après consentement.
- **Newsletter / contenus** (si ajout) : consentement explicite.
